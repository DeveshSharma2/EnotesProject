# EnotesProject

A simple web application for managing notes online. Users can register, login, add, view, and delete their notes.  
This project is built using **Java (Servlet/JSP)** and runs on **Apache Tomcat** web server with **MySQL** as the database.

## Features
- User registration and login
- Add new notes
- View all notes
- Edit existing notes
- Delete notes
- Logout functionality

## Tech Stack
- **Backend**: Java Servlet / JSP  
- **Web Server**: Apache Tomcat  
- **Database**: MySQL  
- **Frontend**: HTML, CSS, JavaScript  
- **IDE**: Eclipse (or any Java IDE)  

## Prerequisites
- JDK 8+  
- Apache Tomcat 8/9  
- MySQL Server  
- Eclipse IDE (optional but recommended)
